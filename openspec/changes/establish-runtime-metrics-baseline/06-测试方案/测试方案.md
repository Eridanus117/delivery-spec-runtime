# 测试计划

## 验证范围

| 层级 | 目标 | 验证方式 |
|---|---|---|
| Schema | 验证事件字段、枚举和报告结构 | JSON Schema 合同测试 |
| 写入行为 | 验证追加、重复、非法、敏感和不安全路径 | Node 内置 `node:test` 临时目录 |
| 汇总行为 | 验证吞吐、耗时、WIP、排队、冲突、返工和完整率公式 | 合成事件夹具 |
| 对照行为 | 验证 C+1 只改变并发并正确触发门槛 | 合成 C/C+1 汇总夹具 |
| 边界 | 验证 Runtime 仓、submodule、同步目录和真实数据不被写入 | 路径守卫与白名单测试 |

## 测试数据

- 只使用合成事件，不使用真实业务事项、请求响应、账号、凭据、绝对路径或机器标识；
- 每个测试在临时私有目录写入 `events-YYYYMMDD.jsonl`；
- 测试完成后递归清理临时目录；
- 公共仓库只保存 schema、合成样例和脱敏汇总样例。

## 场景

| ID | 场景 | 预期 |
|---|---|---|
| MET-001 | 合法完整事件 | 接受并追加 |
| MET-002 | 缺少必填字段或非法枚举 | fail closed，不写入 |
| MET-003 | 重复 `eventId` | 拒绝覆盖并报告冲突 |
| MET-004 | 敏感内容、绝对路径或可逆标识 | 拒绝写入 |
| MET-005 | 不安全或项目内存储目标 | 拒绝写入 |
| MET-006 | 截断或非法 JSONL | 停止采集并报告损坏 |
| MET-007 | 合成 C 基线 | 输出固定指标和数据完整率 |
| MET-008 | 合成 C+1 未达门槛 | 输出回到 C 的建议 |
| MET-009 | 合成 C+1 达到门槛 | 输出可考虑保留，不自动改配置 |
| MET-010 | 样本不足或缺事件 | 输出“无法判断”，不输出成功结论 |

## 基线实验验证

- 观测窗口：10 个满足资格的事项，最长 5 个工作日；
- 最低有效样本：8 个可计算完成事项；
- 少于 20 个样本时只计算中位数，不计算 p95；
- 主指标：吞吐提高至少 10%，首次有用产出时间恶化不超过 10%；
- 护栏：冲突率和返工率增加不超过 5 个百分点，质量门禁失败率增加不超过 3 个百分点，数据完整率至少 95%；
- 任一隐私、完整性或质量门禁回归立即停止并回到 C。

## 通过标准

- 合法事件可解析、可追加、可汇总；
- 非法、敏感、重复和不安全输入均拒绝且不修改既有文件；
- 缺失数据不会被静默补值；
- C/C+1 报告的公式、分母、窗口和门槛固定；
- 不自动上传、同步或修改并发配置。
