# 测试计划

## 验证范围与层级

| 层级 | 目标 | 工具/入口 | 通过标准 |
|---|---|---|---|
| 资产合同 | 证明 skill 存在、frontmatter 合法、五项合同要素齐备 | `test/interaction.test.ts`（Node `node:test`） | 逐要素断言通过；构造缺失要素的副本时对应断言失败 |
| 软链合同 | 证明四条链经 apply 建立、runtime-check fail-closed 覆盖第四条 | 既有 `test/submodule.test.ts` 扩展 | 临时 consumer 中四条链目标正确；破坏第四条链时 runtime-check 非零退出 |
| 兼容回归 | 证明既有 profile、lifecycle、intake、渲染合同不受影响 | 全量 `test/*.test.ts` + `render-commands.ts check` | 全部既有测试与检查通过，无断言放宽 |
| 交付级校验 | 证明 Change 工件与长期 spec 一致 | `openspec validate --all --strict` | 校验通过 |

## 测试环境与数据

| 资产 | 位置 | 生命周期 | 清理责任 |
|---|---|---|---|
| skill 资产本体 | `.claude/skills/delivery-pilot/SKILL.md` | 版本化、公共内容 | 随 Change 回滚删除 |
| 临时 consumer 仓 | `os.tmpdir()`（复用 submodule.test.ts 构造方式） | 单测试 | 测试结束删除 |
| 内容要素断言清单 | `test/interaction.test.ts` 内联常量 | 与源码同 Change | 随 Change 回滚删除 |

不引入网络、账号、真实业务内容或私人流程资产。

## 场景与 Requirement 覆盖

| 场景 ID | Requirement | 前置 | 输入 | 断言 | 清理 |
|---|---|---|---|---|---|
| HI-001 | versioned human-interaction asset | 仓内资产就位 | 读取 SKILL.md | 文件存在；frontmatter 含 name=delivery-pilot 与非空 description；description 覆盖发起类意图词 | 无 |
| HI-002 | 内容完整性可校验 | 同上 | SKILL.md 正文 | 五项要素（发起识别、门口一屏停靠、三动词、沉默=缓+在途提醒、单事项在线）各有对应文本断言；任一要素移除即失败 | 无 |
| HI-003 | fold into three gates | 同上 | SKILL.md 正文 | 含「不替人过门」「机器细节不入人审正文」约定文本 | 无 |
| HI-004 | consumer 可发现 | 临时 consumer + gitlink | `runtime-link.ts apply` | 输出含第四条链；`.claude/skills/delivery-pilot` 为指向 runtime 资产的相对软链 | 删除临时仓 |
| HI-005 | fail-closed 覆盖 | HI-004 后破坏第四条链 | `runtime-entry.ts runtime-check` | 非零退出，错误指明受管路径 | 删除临时仓 |
| HI-006 | existing contracts unchanged | 全仓 | 全量测试 + render check + strict validate | 全部通过 | 测试自理 |

## 断言与停止条件

- 任一既有测试回归失败即停止；不得放宽旧断言。
- skill 缺任一合同要素而测试仍通过时，视为测试失效，先修测试。
- apply/runtime-check 对第四条链未 fail-closed 时停止交付。

## 运行命令

```bash
node --experimental-strip-types --test test/interaction.test.ts
node --experimental-strip-types --test test/*.test.ts
node --experimental-strip-types openspec/tools/render-commands.ts check --runtime-root .
openspec validate --all --strict
```

本文件只定义测试依据；实际运行结论保存于验收工件。
