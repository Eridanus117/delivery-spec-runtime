# 任务 2.3 验证证据

## 交付物

`openspec/tools/workflow-control.ts`：

- 新增 `analysisDir()`：产物落点为资产仓的 `openspec/intake/analysis/<intake-id>/`，目录名即条目 id；若 asset-root 路径段包含 `.delivery-spec-runtime` 则直接拒绝，产物绝不进 Runtime submodule。
- `bind` 支持 `--intake-id`，与 `--change-root` 互斥（分析线发生在立项之前，此时尚无 Change），写出带 `matterId` 的 binding。
- `run` 支持 `--intake-id`，从分析目录读 binding、把 result 写回同目录；并校验目录名、`binding.matterId`、`request.matterId` 三者一致，否则拒绝——否则立项门可能拿另一条目的分析结果放行本条目。
- 新增 `inspect --intake-id`：VC-015 的查询入口，缺产物时输出 `{found:false, missing:[...]}` 并以非零退出，不静默返回空。
