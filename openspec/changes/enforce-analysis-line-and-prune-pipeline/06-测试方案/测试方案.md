## 失败与停止条件

- 任一「不得削弱项」断言（VC-031 / VC-032）与改造前不一致 → **立即停止**，回 `05-改造方案/方案决策.md` 的「重新决策触发条件」第 6 条。
- VC-003 无法成立（一致性测试只能靠两侧互抄实现）→ 停止，触发重新决策条件第 1 条。
- VC-008…VC-011 中任一负向路径无法做到 fail closed（出现「部分写入」）→ 停止，触发重新决策条件第 2 条。
- VC-028 门禁条目无法等价承接 → B4 退回「保留两份现状文档」，在方案决策追加修订记录后继续其余切片。
- VC-027 / VC-029 出现归档目录失败 → 停止；新校验的作用域设计有误，不得以「修改归档目录」的方式绕过。
- `openspec validate --all --strict` 出现非零 → 停止并定位到具体切片，不得通过放宽 strict 或跳过目录消除失败。
- 平台相关的不稳定失败（Windows 路径 / CRLF / 临时目录 EPERM）→ 不得以重试掩盖；登记台账（既有 `INT-20260831-009` / `011` / `012`）后判定是否阻塞。
