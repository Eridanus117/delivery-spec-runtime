# 测试计划

## 验证范围与层级

| 层级 | 目标 | 工具/入口 | 通过标准 |
|---|---|---|---|
| 合同单测 | 证明 `runtime-update` 在启动官方生成器前拒绝 | `node --experimental-strip-types --test test/submodule.test.ts` | 非零退出且错误文本稳定 |
| 文件完整性 | 证明九个 Commands 和三个软链没有变化 | fixture 摘要、`readlinkSync`、Git status | 前后摘要相同，链接目标相同 |
| Git 边界 | 证明父仓 gitlink 与 submodule 均保持 clean | `git status --porcelain` | 父仓指定 submodule 路径为空；submodule 全树为空 |
| Runtime 回归 | 证明既有 schema、control、candidate、bootstrap 合同不受影响 | `node --experimental-strip-types --test test/*.test.ts` | 全部通过 |
| 消费仓 smoke | 证明已升级 gitlink 的仓仍可运行生命周期 | 各仓 `runtime-check`、OpenSpec strict validate | allowed=true，无新增失败 |
| 文档合同 | 证明不再提供实时 update 命令 | 合同测试读取 `opsx-update.md` | 不含实时 wrapper，包含受控升级边界 |

## 测试环境与数据

| 资产 | 位置 | 生命周期 | 清理责任 |
|---|---|---|---|
| 合成 Runtime Git 仓 | `test/submodule.test.ts` 临时目录 | 单测创建、提交、销毁 | `finally rmSync` |
| 合成消费父仓 | 同一临时目录 | 注册 file:// submodule、创建软链、提交、销毁 | `finally rmSync` |
| 九个 Commands 基线 | 合成 submodule 的 `.omp/commands` | 测试开始读取摘要，拒绝后复读 | 不落盘到仓库 |
| 三个真实消费仓 | `agent-system`、`webcoding-spec`、`work-spec` | 只读 smoke，不写 Change | 各仓维护者 |
| OpenSpec CLI | 精确版本 1.10.0 | 测试环境依赖 | Runtime manifest/package lock |

## 场景与 Requirement 覆盖

| 场景 ID | Requirement | 前置 | 输入 | 断言 | 清理 |
|---|---|---|---|---|---|
| RTU-001 | 实时仓禁止执行 OpenSpec Update | 完整 submodule fixture、CLI 可用 | `runtime-entry.ts runtime-update` | status 非零；stderr 指向 Runtime 仓内独立升级 Change | 删除临时根 |
| RTU-002 | 拒绝路径不得修改 Runtime Submodule | `.omp/commands` 是目录软链 | 同 RTU-001 | 九个命令内容摘要不变；submodule status 为空 | 删除临时根 |
| RTU-003 | 拒绝路径不得修改父仓 | 父仓 gitlink 已提交 | 同 RTU-001 | `git status --porcelain -- .delivery-spec-runtime` 为空 | 删除临时根 |
| RTU-004 | 软链合同保持稳定 | 三个 manifest 链接已建立 | 同 RTU-001 | lstat 为 symlink，readlink 前后相同 | 删除临时根 |
| RTU-005 | 命令说明匹配失败语义 | Runtime 工作树 | 读取 `opsx-update.md` | 不含 `runtime-update --asset-root` 可执行 wrapper；说明禁止实时 update | 无 |
| RTU-006 | 既有生命周期不回归 | Runtime 全树 | 全量 Node tests | 全部通过 | 测试自身清理 |
| RTU-007 | 消费仓继续可用 | 消费仓推进新 gitlink 后 | runtime-check + strict validate | allowed=true；原有 specs/changes 验证通过 | 无写入 |

## 自动化资产

```text
test/
└── submodule.test.ts        # 扩展永久回归合同
```

- 不新增 shell runner；fixture 和断言使用 TypeScript/Node 内置模块。
- 不把行为探针输出复制成第二份长期 fixture；验收只保存命令、commit、结论和必要摘要。
- 后续候选升级框架的 fixture/runner 属于另一个 Change，本 Change 不预建空目录。

## 失败停止条件

- `runtime-update` 退出前后任一 Runtime 文件摘要变化。
- 父仓或 submodule 任一 Git status 非空。
- 测试通过依赖删除或绕过 gitlink/dirty/manifest/软链校验。
- 文档仍暗示可在消费仓执行官方 `openspec update`。
- 任一既有 Runtime 合同测试或消费仓 strict validate 新增失败。

## 清理计划

- 所有合成 Git 仓在 `finally` 中递归删除。
- 临时行为探针不进入 Git。
- 失败测试保留 stdout/stderr 于测试报告，不保留真实消费仓副本。
