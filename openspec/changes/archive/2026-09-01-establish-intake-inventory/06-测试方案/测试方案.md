# 测试计划

## 验证范围与层级

| 层级 | 目标 | 工具/入口 | 通过标准 |
|---|---|---|---|
| 合同 | 验证 inventory JSON 字段、枚举和禁止额外结构 | `openspec/contracts/intake-inventory.schema.json` | 合成报告符合 `schemaVersion: 1` |

| 全仓 | 验证白名单、Runtime 边界和严格 OpenSpec 结构 | `node --experimental-strip-types --test test/*.test.ts`、`openspec validate --all --strict` | 无回归、strict 全部通过 |

## 场景与 Requirement 覆盖

| 场景 ID | Requirement | 前置 | 输入 | 断言 | 清理 |
|---|---|---|---|---|---|
| INV-001 | Inventory SHALL scan only controlled Intake assets | 临时根含多个 `INT-*.md` | `intake list` | 条目按相对路径排序，报告为 JSON，文件不变 | 删除临时根 |
| INV-002 | Inventory SHALL scan only controlled Intake assets | 不存在 `openspec/intake/` | `intake list` | 返回空 entries，不创建目录、不扫描根目录 | 删除临时根 |
| INV-003 | Inventory SHALL report duplicate identities | 两个文件具有同一可解析 ID | `intake list` | `duplicateIds` 列出 ID 和全部文件，不选择权威文件 | 删除临时根 |
| INV-004 | Legacy Intake SHALL be visible and non-authoritative | 旧 `status`、缺 `schemaVersion/state/phase` | `intake inspect` | 返回 `legacy`、缺失字段、迁移建议，原文件字节不变 | 删除临时根 |
| INV-005 | Legacy Intake SHALL be visible and non-authoritative | current 与 legacy 共存 | `intake list` | 两者分类独立，不合并状态 | 删除临时根 |
| INV-006 | Inventory output SHALL preserve fail-closed boundaries | 无 frontmatter 文件 | `intake list` | 分类为 `invalid`，报告 `frontmatter` 缺口，不猜测 ID | 删除临时根 |
| INV-007 | 规范化迁移前置 | 当前仓的 legacy/invalid 文件 | 人工逐文件补合同并改主题 slug | 所有 `INT-*.md` 具备唯一当前 ID，原始语义保留，inventory 无重复 ID | 版本历史保留回滚点 |

## 自动化资产

```text
test/intake.test.ts
openspec/contracts/intake-inventory.schema.json
```

- TypeScript 使用 `node --experimental-strip-types`。
- 测试只使用合成内容和临时目录。
- 不把真实 Intake、run-id、trace 或运行结果写入 Change 测试资产。

## 失败与停止条件

- 任何 list/inspect 操作修改 Intake、Runtime submodule 或测试外部路径时立即停止。
- 重复 ID 未列出全部文件、legacy 被标为 current、invalid 被猜测为合法状态时判定 FAIL。
- 既有单文件 Intake 命令行为变化时判定 FAIL。
- 清理失败或测试临时目录残留时判定 FAIL。
- 人工规范化丢失原始语义、覆盖不同事项或产生新重复 ID 时判定 FAIL。

## 数据准备与清理

- 测试在临时目录创建合成 `INT-*.md` 文件和必要目录。
- 每个测试保存目标文件原文，执行 inspect/list 后逐字节比较。
- 动态临时根由测试创建并在 `finally` 中递归删除。
- 当前仓人工规范化只通过版本控制保留变更前内容，不执行批量自动恢复。
