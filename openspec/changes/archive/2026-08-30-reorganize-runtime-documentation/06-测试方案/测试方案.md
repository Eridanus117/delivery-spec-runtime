## 自动化资产

本 Change 不新增永久测试 runner。文档链接检查使用一次性 Node 运行，现有 Runtime 行为继续由 `test/*.test.ts` 防守。

## 失败停止条件

- 任一仓库内 Markdown 链接失效。
- 旧 README 中的有效命令、安全边界或失败语义在新文档中无归属。
- 文档命令与工具实际参数不一致。
- fresh reviewer session 存在 OPEN finding。
- renderer、合同测试或 strict validation 失败。

## 清理

- 删除临时链接检查输出和审查输入文件。
- 文档变更不创建远程资源或消费仓副作用。
