# 任务 3.1 验证证据

## 交付物

`openspec/tools/intake-control.ts`：

- 常量层：`stages` / `nextStage` 两个中间站状态机被移除，替换为 `terminalStates`（promoted / held / closed）、`legacyPhases`（只读兼容）与 `requiredSections`（五小节）。
- `advance`：保留命令名但不再有合法用途。接受可选 `--to`，任何调用一律非零并说明「中间站已随登记并站移除，请直接使用 promote、hold 或 close」。该函数只 `parse` 不写盘，因此拒绝时文件逐字节不变。
- `promote` / `hold` / `close`：删除 `phase !== "disposition"` 前置条件，改为「已处置的条目不得重复处置」。`captured` 状态可一次到终态。
- `reopen`：回到 `captured`（原先写 `triaged` 并把 phase 改回 `triage`），且不再写 `phase`。
- 四元枚举：新写入只产生 `captured` / `promoted` / `held` / `closed`；`triaged` 仅保留在解析侧供存量条目读出。
- `phase` 降为只读兼容字段——处置、reopen 全链路都不再调用 `replaceFrontmatter(content, "phase", ...)`。
