## 观察与停止条件

- 观察 profile registry、workflow binding、阶段状态和 `publishedInputs` 输出是否与合同一致。
- 若发现既有 profile 行为回归、阶段循环状态错误、输出字段不一致或入口门禁失败，停止发布并回滚本次 PR。
- 不得绕过 runtime-check、strict validation、Review、Acceptance 或 Archive guard。

## 回滚计划

- 回滚最终 PR，恢复到 Change 实施前的 Runtime commit。
- 保留归档 Change、Review、Acceptance、Readiness 和运行证据，不删除审计记录。
- 若回滚后需要再次实现，创建新的 Change；不得在已归档 Change 上覆盖修复。

## 交付限制

- 不保存尚未发生的 PR URL、合并 commit 或 release-id。
- 不自动创建 Change、读取 Desk 或向外部资产写回。
